ccam

Claude Code Account Manager

Manage and use multiple claude CLI accounts on one machine, from a local web UI backed by a no-admin background service.

macOS / Linux:

curl -fsSL https://ccam-six.vercel.app/install.sh | sh

Windows (PowerShell):

irm https://ccam-six.vercel.app/install.ps1 | iex
